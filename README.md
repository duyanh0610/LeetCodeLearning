# LeetCode Practice - 13 dạng x 2 tuần

Mục tiêu: luyện thuật toán để đi phỏng vấn. Code bằng TypeScript.

## Nhịp học của mỗi dạng (14 ngày)
- **Ngày 1**: học lý thuyết của dạng (ý chính, template, dấu hiệu nhận biết). Không giải bài.
- **Ngày 2–13**: mỗi ngày 2 bài của dạng đó (24 bài/dạng), từ dễ đến khó.
- **Ngày 14**: ôn lại bài chưa tự giải được + mock 1 bài mới bấm giờ.
- Xong 14 ngày thì sang dạng tiếp theo. Tổng cộng 13 dạng ≈ 26 tuần.

Trước khi bắt đầu, đọc [00-foundations.md](plan/00-foundations.md) (Big-O, cấu trúc dữ liệu, bảng nhận diện dạng, quy trình phỏng vấn).

## Cách làm mỗi bài
1. Tự nghĩ 25–30 phút → bí thì xem gợi ý → **tự code lại không nhìn**.
2. Lưu code vào [solutions/](solutions/) dạng `<số>-<tên-bài>.ts`.
3. Ghi thời gian + bài học vào bảng của dạng.
4. Bài không tự giải được: làm lại sau 1, 3, 7 ngày.
