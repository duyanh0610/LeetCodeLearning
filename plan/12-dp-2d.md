## Ngày 1 - Lý thuyết

### Ý chính
- State có 2 chiều: (i, j) trên grid, hoặc (i trên chuỗi A, j trên chuỗi B), hoặc (item, capacity).
- Vẽ bảng nhỏ bằng tay để tìm transition; có thể nén còn 1 hàng.
- Mẫu: đường đi trên grid, LCS/Edit distance, knapsack.

### Template (TypeScript)
```ts
const dp = Array.from({ length: m + 1 }, () => new Array(n + 1).fill(0));
for (let i = 1; i <= m; i++)
  for (let j = 1; j <= n; j++)
    dp[i][j] = a[i-1] === b[j-1] ? dp[i-1][j-1] + 1 : Math.max(dp[i-1][j], dp[i][j-1]);
```
