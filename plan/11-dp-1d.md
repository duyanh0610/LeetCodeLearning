### Ý chính
- DP = bài toán con gối nhau + công thức truy hồi. Quy trình: định nghĩa state -> transition -> base case -> thứ tự tính.
- Bắt đầu từ đệ quy + memo (top-down), rồi chuyển bottom-up, rồi tối ưu bộ nhớ.
- Mẫu: fibonacci-like, chọn/không chọn (knapsack), LIS.
